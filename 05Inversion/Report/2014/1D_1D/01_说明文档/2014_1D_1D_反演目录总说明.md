## 四、文献标准筛选规则

当前采用的是王亚东文献风格的筛选逻辑，针对三个目标周期 `3.0 s`、`3.5 s`、`4.0 s` 执行。核心规则如下。

- 信噪比阈值：`SNR >= 4.0`。
- 群速度上限规则：`T < 4.5 s` 时上限 `3.0 km/s`，`T >= 4.5 s` 时上限 `3.3 km/s`。由于本次只处理 `3.0/3.5/4.0 s`，实际全部使用 `3.0 km/s`。
- 群速度下限：`0.0 km/s`。
- 一波长距离约束：`D >= 1 * V_ref(T) * T`。这就是这里“台间距”筛选的实际落地形式，真正约束的是路径长度是否大于等于对应周期的一波长距离。
- 周期跳枝校正：`branch_n = round((D / Vref - t_raw) / T)`，`t_corrected = t_raw + branch_n * T`。
- 最终二维成图直接使用 `measurements_period_corrected.csv`。

## 七、绘图风格说明

当前 Figure 6 已经切换到你确认的 `Candidate A paper standard smooth` 风格，具体体现在：

- 字体采用 `Times New Roman / serif`。
- 配色采用 Wang 论文风格的黑-红-黄-白-青-蓝-紫渐变。
- 绘图方式采用 `nan Gaussian smoothing + cubic upsampling`，不再以原始像素方格作为最终报告图。
- 子图强制正方形显示，并统一使用经纬度刻度格式。
- 当前 `Report` 中保存的是平滑后的正式 Figure 6；像素版只作为运行过程中的中间图，不保留在 `Report`。

对应脚本为：
- `plot_wang_fig5_fig6_from_disperpicker.py`：主反演与主出图脚本，现在会默认生成平滑版 Figure 6。
- `replot_wang_figure6_colormap.py`：Candidate A 风格的平滑重绘脚本，负责把网格结果转换为论文风格的 Figure 6。

## 八、命令行是否一致

两套数据使用的是同一套代码，但命令行不完全一致，因为输入曲线目录不同，同时输出目录也不同。因此这里需要分别写出两条命令。

### 1. 去除尖峰数据

```bash
/mnt/data_hdd/MSH_ANT_Final/05Inversion/Report/2014/1D_1D/02_代码/05_二维成图脚本/从04重建二维相速度图.sh \
  --spike-mode remove \
  --output-root /mnt/data_hdd/MSH_ANT_Final/05Inversion/2014/1D_1D/01_去除尖峰数据
```

### 2. 不去除尖峰数据

```bash
/mnt/data_hdd/MSH_ANT_Final/05Inversion/Report/2014/1D_1D/02_代码/05_二维成图脚本/从04重建二维相速度图.sh \
  --spike-mode nonremove \
  --output-root /mnt/data_hdd/MSH_ANT_Final/05Inversion/2014/1D_1D/02_不去除尖峰数据
```

如果只看“代码脚本本身”是否一致，答案是完全一致；如果看“实际运行命令”是否一字不差，答案是不一致，因为 `--spike-mode` 和 `--output-root` 不同。

# 01RawData 文件说明

生成日期：2026-07-08

本目录保存 Mount St. Helens ANT 项目的原始波形数据和台站元信息数据。波形数据为后续预处理、互相关、叠加、频散提取和层析成像的原始输入；元信息数据为 StationXML/响应文件，用于台站定位、仪器响应核查和绘制台站分布图。

## 一、每年的数据内容

数据按年份组织为 `2014` 和 `2017` 两组，每组再分为 `WaveData` 和 `MetaData`。`WaveData` 保存每日 miniSEED 波形，`MetaData` 保存对应台站的 StationXML/响应元信息。

目录规模：`2014` 年原始数据目录约 392G，`2017` 年原始数据目录约 149G。

## 二、波形数据说明

- 文件格式：miniSEED，按台站分目录保存，每个文件对应一个自然日或一个日记录。
- 时间字段：逐台站表中的 `first_file_date` 和 `last_file_date` 由完整文件名解析得到，表示该台站在本整理目录中保存的最早和最晚日文件日期。
- 采样率和分量：由每个台站代表日文件的 miniSEED 首记录读取。当前整理数据均为垂向分量 `Z`；1D/YI 为 `DPZ`，XD 为 `HHZ`，永久台站包含 `BHZ`、`EHZ`、`ENZ`、`HHZ`、`HNZ` 等垂向通道，具体以逐台站表为准。
- 采样率：1D/YI 原始日文件为 250 Hz；XD 为 100 Hz；永久台站随台站和通道不同，2014 年为 50/100 Hz，2017 年为 40/50/100/200 Hz，具体以逐台站表为准。
- miniSEED 编码：当前抽读结果为 Steim-2 编码编号 `11`，记录长度为 4096 bytes。

## 五、台站分布图复现

旧目录 `/mnt/data_hdd/MSH_ANT/outputs/figures/station_maps` 中原本只有 2014 年 clean-frame 版本，2017 年只有普通 GMT 版本。本次补齐 2017 年 clean-frame 版本，并将代码和图片统一改为简洁命名。

复现命令：

```bash
cd /mnt/data_hdd/MSH_ANT_Final/01RawData/Reports
MSH_ANT_METADATA_ROOT=/mnt/data_hdd/MSH_ANT_Final/01RawData \
MSH_ANT_OUTPUT_DIR=/mnt/data_hdd/MSH_ANT_Final/01RawData/Reports \
/home/lenovo/anaconda3/envs/noise/bin/python plot_stations.py
```

注意：绘图脚本依赖 GMT、Pillow，以及 GMT 地形网格 `@earth_relief_15s` 和 `@earth_relief_01s`。若 Lenovo 本地 GMT 缓存缺少这些网格，需要先补齐 GMT 远程数据缓存。
